A small static homepage for my current projects:

- ATAR Dash
- ATAR Shooter
- GIF Maker
- Prayer Times
- Daily Deen

## Deploying on Vercel

This is a static site. Vercel can deploy it directly from the repository with:

- Framework preset: Other
- Build command: none
- Output directory: `.`

The homepage is `index.html`.
